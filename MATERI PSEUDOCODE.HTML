🧠 Apa Itu Pseudocode?

Pseudocode adalah cara menuliskan langkah-langkah penyelesaian masalah menggunakan bahasa sederhana yang menyerupai bahasa pemrograman.

Pseudocode belum terikat pada bahasa pemrograman tertentu.

📥 INPUT

Data yang dimasukkan

⚙️ PROCESS

Data yang diolah

📤 OUTPUT

Hasil yang ditampilkan

📘 BAB 1 — Mengenal Pseudocode

Pseudocode digunakan untuk membantu kita merancang logika program sebelum menulis kode sebenarnya.

Contoh:

BEGIN

INPUT panjang
INPUT lebar

luas ← panjang × lebar

OUTPUT luas

END
Catatan penting:

Simbol ← dibaca "diisi dengan" atau "mendapat nilai dari".

Contoh: 

luas ← panjang × lebar

Dibaca: Luas diisi dengan panjang dikali lebar.

📘 BAB 2 — Pseudocode dan IPO

Bagian Contoh
INPUT harga, jumlah
PROCESS harga × jumlah
OUTPUT total harga

Contoh:

BEGIN

INPUT harga
INPUT jumlah

total ← harga × jumlah

OUTPUT total

END

📘 BAB 3 — Aturan Dasar Pseudocode

Perintah Fungsi
BEGIN Awal algoritma
END Akhir algoritma
INPUT Memasukkan data
OUTPUT Menampilkan hasil
IF / THEN Percabangan kondisi
ELSE Jika kondisi tidak terpenuhi
ENDIF Akhir percabangan
FOR Perulangan dengan jumlah tertentu
WHILE Perulangan berdasarkan kondisi

📘 BAB 4 — Variabel dan Tipe Data

Variabel adalah tempat untuk menyimpan data yang nilainya dapat berubah. 

nama ← "Andi"

umur ← 16

tinggi ← 165.5

lulus ← TRUE
Tipe Data Contoh
Integer 16
Real 165.5
String "Andi"
Boolean TRUE / FALSE

📘 BAB 5 — Operator Aritmatika

Operator Arti
+ Penjumlahan
- Pengurangan
* Perkalian
/ Pembagian
MOD Sisa pembagian

Contoh:

a ← 10
b ← 5

jumlah ← a + b

selisih ← a - b

kali ← a * b

bagi ← a / b

📘 BAB 6 — Sekuensial

Sekuensial berarti instruksi dilakukan satu per satu dari atas ke bawah. 

BEGIN

INPUT panjang
INPUT lebar

luas ← panjang * lebar

OUTPUT luas

END

Urutannya:

INPUT → PROCESS → OUTPUT

📘 BAB 7 — Percabangan

Percabangan digunakan ketika program harus memilih tindakan berdasarkan kondisi.

IF – THEN

IF nilai >= 75 THEN

    OUTPUT "Lulus"

ENDIF

IF – THEN – ELSE

IF nilai >= 75 THEN

    OUTPUT "Lulus"

ELSE

    OUTPUT "Belum Lulus"

ENDIF

Percabangan Bertingkat

IF nilai >= 90 THEN

    OUTPUT "A"

ELSE IF nilai >= 80 THEN

    OUTPUT "B"

ELSE IF nilai >= 75 THEN

    OUTPUT "C"

ELSE

    OUTPUT "D"

ENDIF

📘 BAB 8 — Operator Perbandingan dan Logika

Operator Arti
= Sama dengan
≠ Tidak sama dengan
> Lebih besar
< Lebih kecil
≥ Lebih besar atau sama
≤ Lebih kecil atau sama
AND Dan
OR Atau
NOT Tidak

Contoh:

IF nilai >= 75 AND kehadiran >= 80 THEN

    OUTPUT "Lulus"

ENDIF

📘 BAB 9 — Perulangan

Perulangan digunakan ketika suatu perintah harus dilakukan berkali-kali.

FOR

FOR i ← 1 TO 5

    OUTPUT i

END FOR

WHILE

i ← 1

WHILE i <= 5

    OUTPUT i

    i ← i + 1

END WHILE
FOR cocok ketika jumlah pengulangan sudah diketahui.

WHILE cocok ketika pengulangan bergantung pada kondisi.

📘 BAB 10 — Contoh Pseudocode Lengkap

Program Penilaian Siswa

BEGIN

INPUT nama
INPUT nilai

IF nilai >= 75 THEN

    OUTPUT nama
    OUTPUT "Lulus"

ELSE

    OUTPUT nama
    OUTPUT "Belum Lulus"

ENDIF

END

Program Harga Barang dan Diskon

BEGIN

INPUT nama_barang
INPUT harga
INPUT jumlah

total ← harga * jumlah

IF total >= 100000 THEN

    diskon ← total * 10 / 100

ELSE

    diskon ← 0

ENDIF

bayar ← total - diskon

OUTPUT total
OUTPUT diskon
OUTPUT bayar

END

📘 BAB 11 — Dari Pseudocode ke Program

Pseudocode menjadi jembatan menuju kode program.

Pseudocode:

BEGIN

INPUT nama

OUTPUT "Halo"

OUTPUT nama

END

Contoh JavaScript:

let nama = prompt("Masukkan nama:");

alert("Halo " + nama);

📘 BAB 12 — Cara Membuat Pseudocode

  1. Pahami masalah.
  2. Tentukan INPUT.
  3. Tentukan PROCESS.
  4. Tentukan OUTPUT.
  5. Susun langkah secara berurutan.
  6. Tentukan apakah membutuhkan percabangan atau perulangan.
  7. Uji pseudocode menggunakan contoh data.
MASALAH → INPUT → PROCESS → OUTPUT → PSEUDOCODE → PROGRAM

📘 BAB 13 — Kesalahan yang Sering Terjadi

  • Tidak menentukan input.
  • Urutan langkah tidak logis.
  • Kondisi percabangan tidak jelas.
  • Lupa ENDIF.
  • Lupa memperbarui variabel pada WHILE.
  • Output tidak sesuai tujuan.

📘 BAB 14 — Latihan Bertahap

  1. Hitung luas persegi.
  2. Hitung luas persegi panjang.
  3. Hitung total harga barang.
  4. Tentukan lulus atau belum lulus berdasarkan nilai ≥ 75.
  5. Tentukan bilangan genap atau ganjil menggunakan MOD.
  6. Tentukan kategori nilai A, B, C atau D.
  7. Tampilkan angka 1 sampai 10 menggunakan FOR.
  8. Tampilkan nama siswa sebanyak 5 kali.
  9. Hitung total belanja dan diskon 10% jika total minimal Rp100.000.
  10. Buat pseudocode dari masalah nyata di lingkungan sekolah.
